# 節慶賀卡：聊天版提示詞（ChatGPT／Gemini）

不用安裝任何東西、不用 API 金鑰。打開 ChatGPT 或 Gemini，上傳自己的照片和一隻動物的照片，貼上兩段提示詞，就能做出「自己＋動物」的盲盒公仔節慶賀卡。

想要固定角色、一次出 4 張候選、程式疊字、延伸成三種尺寸，用本 plugin 的產線版（見 `SKILL.md`）。

> 2026-10-11 用兩組真人照片＋同一隻狗，在 ChatGPT 與 Gemini App 實測國慶、中秋，以及 Gemini API 實測國慶、中秋、聖誕。

---

## 為什麼分兩步

一步做完時，模型手上只有真人照片，會在「像照片」和「像公仔」之間折衷：ChatGPT 畫成寫實大頭照貼在 Q 版身體上，Gemini 畫成黑點眼的普通公仔。
先在同一個對話裡把照片轉成盲盒公仔，第二步只要「照這組公仔」，軟膠質感和角色一致性都穩很多。公仔做一次就好，之後換節日只要再貼一次第二步。

## 準備兩張照片

- **第一張**：你自己的照片。正面、臉清楚、看得到上半身的衣服
- **第二張**：一隻動物的**實拍照片**（寵物、動物園拍的都行）。不要用卡通圖
- **順序很重要**：先人、後動物，提示詞用「第一張」「第二張」區分
- 只上傳自己、或有對方同意的人的照片；照片會傳到 OpenAI／Google 的伺服器

---

## 第一步：照片變成盲盒公仔

公仔不滿意就請它重做，滿意了再做第二步——第二步會照公仔原樣出場。

```text
請把第一張照片裡的人和第二張照片裡的動物，做成一組 3D 軟膠盲盒公仔，像潮玩店賣的那種收藏公仔，並排站在純白背景上，正面全身。
【人】大頭小身，頭大約佔全身高度的 40%，圓潤的小身體、短手短腳。臉型、五官的位置、膚色、髮型、髮色、衣服都照照片做；照片裡有的配件（例如眼鏡、項鍊、痣）才做，沒有的不要加。頭髮做成一束一束雕塑出來的軟膠造型。眼睛是大大圓圓、有虹膜和亮點反光的公仔眼睛，表情溫和地微笑。
【動物】照照片的品種、毛色、花紋和臉型，眼睛大小和臉型照照片，不要畫成大眼睛的動物寶寶臉；做成同一系列的公仔，比人小，坐在人的腳邊。
【材質】整組都是光滑霧面的軟膠，沒有毛孔、皺紋或照片的質感，柔和的攝影棚燈光。畫面裡不要有任何文字。
```

## 第二步：公仔做成賀卡

在**同一個對話**接著貼，改前三行：

| 行 | 怎麼填 |
|---|---|
| 節日 | 必填，例如「國慶」「中秋節」「萬聖節」「寒露」「生日」。台灣節日照台灣的過法，外國節日（萬聖節、聖誕節、復活節、感恩節）照原本的傳統 |
| 場景 | 可留白（AI 依節日自己設計）；想指定就寫一個詞或一句話，例如「遊行」「家裡陽台烤肉」 |
| 祝賀詞 | 可留白（AI 自己寫一句）；自己寫就**不超過 8 個中文字**（越長越容易寫錯字），會一字不改放上去，英文由 AI 翻 |

```text
用這組公仔（人和動物）做一張「國慶」祝賀卡。
場景：「遊行」（空白就依節日自己設計）
祝賀詞：「」（不超過 8 個中文字；空白就依節日自己寫）

【角色】人和動物照這組公仔原樣出場：長相、髮型、衣服、配件、軟膠材質和頭身比例都不變，只換動作、表情和手上的道具（換成符合節日的東西）。動物比人小，自然地陪在旁邊（會飛的停在肩上，四隻腳的在腳邊）。
【場景】把公仔放進一個精緻的微縮場景裡拍攝：場景的東西也是公仔和模型的質感，柔和的光線，背景帶一點景深模糊。依節日的傳統習俗設計；台灣節日照台灣的過法（例如國慶是中華民國雙十國慶），外國節日照原本的傳統。
【祝賀詞】上面有寫祝賀詞就照寫，一字不改；空白就自己寫一句不超過 8 個中文字的繁體中文祝福語（祝福的話，不是場景標題），不要提生肖或年份。用清楚不透明的字直接寫在畫面上方，下面一行小字放意思相同的英文；祝賀詞只寫一次。
【版面】直式 4:5，上方三分之一留給祝賀詞，角色在下半部。祝賀詞直接寫在場景的天空或背景上，不要另外留白色或單色的色塊。
【限制】畫面滿版，不要畫卡片的邊框或外框；主角只有這一個人和這一隻動物（背景可以有路人，但不要有其他動物），節日的代表動物（例如復活節兔子）只能是很小的擺飾；同樣的東西不重複；除了祝賀詞，畫面上不要有任何文字或數字，不畫春聯、福字、招牌。
```

## 用 ChatGPT 還是 Gemini？

兩邊都做得出盲盒軟膠感，擅長的不一樣：

| 比較在意 | 用 | 要接受的地方 |
|---|---|---|
| **人像本人**：衣服款式、印花、表情 | ChatGPT | 動物常被畫成大眼睛的可愛幼崽，不太像照片那隻（試過四種寫法都改不掉） |
| **動物像照片那隻**：臉型、耳朵、坐姿 | Gemini | 衣服細節可能跑掉（例如長袖變短袖）；花車、看板偶爾冒出數字 |

都想要就兩邊各做一次，挑喜歡的那張。

## 生出來不滿意？在同一個對話接著說

| 狀況 | 說這句 |
|---|---|
| 公仔不像我（第一步） | 臉型和髮型要更像第一張照片，再做一次公仔 |
| 祝賀詞寫錯字 | 祝賀詞的字寫錯了，請只修正文字，畫面其他地方不要動 |
| 背景冒出小字 | 把背景裡的字都拿掉，祝賀詞保留 |
| 字壓到頭 | 角色再往下、再小一點，上方留更多空間給字 |
| 想要正方形或橫式 | 把這張改成正方形 1:1（或橫式 16:9），人物和動物的長相、身材比例、動作完全不要變，只延伸兩側的場景 |

## 每一條規則對應一個踩過的錯

- 「照片裡有的配件才做，沒有的不要加」：寫成「保留眼鏡」時，沒戴眼鏡的人被畫上眼鏡
- 「髮色、衣服照照片做」：沒寫時頭髮常被一律畫成黑色
- 「祝賀詞直接寫在場景背景上，不要白色或單色色塊」：Gemini 會在上方留一塊白底放字，畫面不滿版
- 「背景不要有其他動物」：遊行場景曾多出好幾隻狗
- 「不要提生肖或年份」：AI 不知道是哪一年，會套錯生肖
- 「台灣節日照台灣的過法（國慶是中華民國雙十國慶）」：沒講清楚是哪國時國旗會畫錯；講清楚後國旗正確
- 「祝賀詞清楚、不透明」「只寫一次」：曾出現半透明色帶裡的模糊假字、同一句寫兩次
- 「節日代表動物只能是小擺飾」：復活節兔子會跟上傳的動物搶位置
- 「畫面滿版，不要卡片外框」：說「祝賀卡」時，AI 有時會畫出一張實體卡片的框
- 「同樣的東西不重複」：中秋曾畫出兩個月亮
- 「祝福的話，不是場景標題」：指定場景「遊行」時，祝賀詞曾寫成「國慶遊行」
- 規則的**詳細程度本身會影響效果**：「不要畫卡片的邊框或外框」縮成「不要邊框」就失效
