# 影片提示詞結構

## §1 共同骨架

商品短影音、敘事短片都用同一套：

1. **規格宣告** — 秒數、比例、風格（UGC／電影感／科技感）、拍攝方式（手機手持／穩定器）
2. **主角與商品鎖定** — 人物一致性（見 character-lock.md）＋商品外觀必須與參考圖一致、不可改款、不可出現其他品牌 Logo
3. **逐段分鏡** — 標秒數，每段寫：鏡位＋動作＋畫面重點＋（有的話）字幕
4. **口播逐字** — 獨立一段寫完整台詞，方便另外配音
5. **負面清單** — 見 negative-prompts.md

秒數切法：10 秒切 3–4 段、15 秒切 5 段。要求極精準時可切到一秒一段，代價是指令很長。

## §2 三個常用控制技巧

**文字模糊化**
商品上有文字（姓名貼、包裝字、招牌）時，與其讓模型生出簡體字或亂碼，
不如明確要求：「所有文字必須不可讀、模糊、抽象化，不要出現清楚文字」，
同時描述文字的**視覺排列**（小型重複排列、規律排布）而非內容。

**用排除法控畫面**
「全片禁止出現任何人類、人手、人腳或人影」比「只拍狗」可靠。
不要什麼，就直接列出來。

**物理連續性約束**
動作類影片必寫，且要具體到指名該物件。例：
- 「雨傘全程保持完整撐開，不可收合、不可消失、不可變形」
- 「必須清楚從兩個障礙物之間真正存在的空隙穿過，絕對不能穿模」
模型很容易讓道具中途消失或角色穿過實體，這類句子省不得。

## §3 完整範例：商品短影音（10 秒，原創範例：摺疊晴雨傘）

```
生成一支 10 秒直式短影音，比例 9:16。
UGC style, photorealistic, smartphone camera, handheld camera,
natural lighting, real street scene, 4K, high detail。

主角是一位 25–35 歲亞洲上班族女性，自然妝容，黑色短髮，
米色風衣配深色長褲，保持 same person, same face, same hairstyle,
same outfit, no outfit change。

商品是霧灰色自動摺疊晴雨傘。嚴格依照提供的商品參考圖：
保持傘布顏色、傘骨數量、手柄造型與收納袋樣式，不可自行改款、
不可出現其他品牌 Logo。傘面全程保持完整撐開狀態時不可變形、不可穿模。

0–2 秒：捷運站出口，外面下著雨，主角在出口停下腳步看向雨幕。
2–5 秒：從包包拿出摺疊傘，按鍵自動開傘的近拍，水珠在傘面滑落。
5–8 秒：主角撐傘走進雨中，側面跟拍，傘面擋雨的效果清楚可見。
8–10 秒：雨停，收傘抖水，傘收進收納袋放回包包，畫面乾淨自然。

口播：「常常突然下雨的季節，包包裡放一支自動摺疊傘，
開傘收傘一顆按鍵搞定，有需要可以看看！」

Strictly no readable text in the video. No price, no discount,
no platform UI, no subtitles, no watermark, no logo text.

Negative Prompt:
cartoon, CGI, TV shopping style, fake product, redesigned product,
altered umbrella color, broken ribs, deformed hands, extra fingers,
different umbrella between shots, camera flicker, generated text.
```

## §4 受規範商品的合規句型

食品、保健食品、化妝品、醫療器材類**必加**：

- 不做療效保證、不宣稱功效
- 價格、活動、規格、成分、食用方式一律以商品頁最新資訊為準
- 不虛構優惠、不做電視購物感、不過度演戲
- 結尾導回商品頁：「有需要可以看看商品頁，資訊以頁面為準」

**注意**：以上是業界自律標準，不是法規標準。台灣《食品安全衛生管理法》《化粧品衛生安全管理法》
對廣告另有規定，涉及實際商業使用時應提醒使用者自行查證。

## §5 文案生成的輸出結構

不是畫面提示詞，是給 LLM 的 output schema。丟一張商品圖就能產出整包素材：

```
【切角分析】
- 目標受眾／最常出現的生活情境／真實困擾
- 商品帶來的價值／最適合切入角度／建議內容情緒／最適合平台

【商品分析】
- 商品名稱／品牌／分類／類型
- 商品外觀（顏色、造型、標籤、主視覺調性）
- 商品特色（條列，只寫圖片上看得到的）
- 使用情境／核心賣點

【各平台文案】
（依上面判斷的平台產出）
```

規則：商品特色**只寫圖片上看得到的**，看不到的規格寫「以商品頁為準」，不要腦補。
