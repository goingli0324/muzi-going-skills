# 風格配方庫

八種風格，每則包含：**適用情況 → 關鍵字串 → 範例骨架**。
用法是換掉主體與場景，保留關鍵字串。範例骨架刻意留【】欄位給實際需求替換。

---

## §1 3D chibi 公仔／微縮場景

**適用**：人物公仔化、節慶場景、畢業／開學／週年紀念圖

**關鍵字串**
`cute chibi figurine, 3D render, collectible toy proportions, slightly oversized head,
big expressive eyes, smooth toy-like texture, miniature diorama, soft studio lighting,
highly detailed, clean polished rendering`

**範例骨架**（畢業紀念微縮場景）

```
Create a heartwarming 3D chibi graduation diorama scene.

【主角】: a cute chibi graduate figurine wearing a black gown and cap,
holding a rolled diploma, joyful smile, based on the uploaded photo
(keep face identity, see character-lock).

Around the main figure, arrange smaller miniature chibi figures as a
memory-collection display: 【同學／師長／社團道具等 3–5 個小配角】.

Background: campus gate in miniature, confetti in the air, warm afternoon
sunlight, pastel flowers, dreamy bokeh.

Style: premium collectible figurine quality, adorable proportions,
cinematic warm lighting, shallow depth of field, ultra detailed, 8K.

Negative: realistic human proportions, creepy doll, plastic cheap toy look,
distorted face, extra fingers, text, watermark, logo.
```

## §3 高衝擊社群封面

**適用**：IG／FB 封面、課程宣傳圖、個人品牌視覺

**結構**（六段）：人物設定／背景設定／畫面元素細節／視覺風格／構圖要求／負面限制

**經典手法：突破框架**——讓人物從某個「框」（手機螢幕、畫框、書頁、車窗）衝出來，
框內是虛擬、框外是現實，破裂處加碎片與速度感。

**本地化重點**：背景可直接指定台灣地標增加親切感——
台北 101 夜景、西門町霓虹街頭、高雄流行音樂中心、台中歌劇院、
台南神農街夜景、淡水漁人碼頭、九份山城夜景。

**範例骨架**

```
請使用我提供的人物照片作為主要臉部與身形參考，保留五官特徵、髮型、神韻。

創作一張 9:16 高衝擊社群封面海報。

畫面主題：一本巨大的攤開書本立在畫面中，人物從書頁裡衝破出來，
紙張撕裂、紙屑與文字碎片飛散，帶強烈速度感與立體感。

人物設定：穿著【風格】服裝，姿勢有動感，一手向鏡頭前伸形成強烈透視，
表情自信，像雜誌封面人物。

背景設定：【台灣地標夜景，任選上列】，城市燈光、霓虹反射、電影感夜景氛圍。

視覺風格：超寫實攝影、電影感、高反差光影、3D 立體透視、廣角低角度、
臉部清楚、真實皮膚質感、sharp focus on face、8K、cinematic lighting。

構圖要求：人物一部分在書頁裡、一部分伸出到現實空間；臉不能變形、
比例自然不要大頭小身；碎片圍繞人物與書頁邊緣。

負面限制：不要卡通、不要低畫質、不要臉歪、不要多手多腳、
不要文字亂碼、不要品牌 Logo、不要臉部模糊、不要道具變形。
```

## §4 治癒系寫實人像（純中文寫法）

**適用**：不想混用英文關鍵字時；溫暖、療癒、生活感的人像

**結構**（六段）：畫面內容／場景環境／畫面風格／畫質參數／負向指令／風格約束

**關鍵字串**（中文）
`治癒浪漫氛圍、電影級寫實質感、層次柔光光影、深景深、高清細膩紋理、真實毛髮質感、
自然立體陰影、4K 超高畫質、電影膠片色調、專業人像攝影構圖、純真人寫實風`

**範例骨架**（海邊木棧道黃昏）

```
畫面內容：亞洲短髮女生，穿鵝黃色針織外套、白色長裙，牽著一隻柴犬
走在海邊木棧道上，回頭對鏡頭微笑
場景環境：黃昏海岸，橘粉色晚霞染滿天空，海面碎金反光，
遠處燈塔亮起暖黃燈，海風吹動裙擺與髮絲
畫面風格：治癒浪漫氛圍，電影級寫實質感，層次柔光光影，深景深，
高清細膩紋理，真實毛髮質感，自然立體陰影
畫質參數：4K 超高畫質，細節拉滿，電影膠片色調，專業人像攝影構圖
負向指令：拒絕五官變形、肢體錯位、動物長相怪異、畫面模糊、低畫質、
雜亂光影、多餘文字水印、過度曝光、比例失調
風格約束：色調冷暖對比柔和，氛圍寧靜溫暖，人物與寵物動作自然協調，
無二次元動漫風格，純真人寫實風
```

## §6 超微距喜劇場景

**適用**：誇張搞笑、反差萌、社群迷因圖

**排版**：一句一行（見 frameworks.md §2），每個指令獨立成行

**關鍵字串**
`macro photography, cinematic 3D render, exaggerated chibi proportions,
extreme low angle, dramatic perspective, motion blur, volumetric light,
creamy bokeh background, animation-film quality + photorealistic fusion, 8K`

**寫法要點**
- 主角與配角都給**誇張到極限的表情**（瞪大眼、下巴掉下來、嚇到彈起來）
- 場景選日常微縮空間（桌面、廚房流理台、陽台花盆），反差感來自「小空間裡的大事件」
- 補一個「錯愕圍觀者」配角，喜劇感會多一層
- 收尾堆質感與情緒詞：收藏級細節、迷因級反應臉、一眼停留、情緒張力拉滿

**範例骨架**（一句一行節錄）

```
超微距攝影風格，電影級 3D 渲染。
廚房流理台上，一隻 Q 版倉鼠戴著廚師帽，驚恐地騎著電動打蛋器逃亡。
後方一坨巨大的麵糊怪物緩緩逼近，表情呆萌但充滿壓迫感。
旁邊一隻表情超級錯愕的 Q 版麻雀站在醬油瓶蓋上圍觀。
超低角度鏡頭。
強烈速度感。
動態模糊。
景深極淺，背景奶油化散景。
暖色聚光燈從抽油煙機灑落。
收藏級公仔細節。
迷因級反應臉。
9:16 滿版構圖。
```

## §7 動漫角色設定圖

**適用**：IP 角色前置作業。一段話產出三視圖＋表情＋配件，做虛擬人物素材庫最省事。

**範例骨架**

```
使用我上傳的照片，把人物轉換為日式電影級動漫風格，做成一張角色設定圖。
角色設定圖：橫式 16:9。左側 2/3 是角色全身站立圖，呈現正面／側面／背面
三個角度；右上是四個表情（依角色個性生成）；右下是角色的隨身配件。
```

**用途**：先產設定圖、再拿設定圖當後續生圖生影片的一致性參考，
比每次都重新描述角色穩定得多。續拍時開頭寫「如角色設定圖」即可。

## §8 2.5D 橫向動作遊戲風

**適用**：遊戲感短影音、動作連續性要求高的畫面

**關鍵字串**
`2.5D side-scrolling action game style, bright fantasy battlefield,
saturated colors, soft volumetric light, clean character silhouettes,
exaggerated but weighty hit reactions, high frame rate smooth motion`

**寫法要點**
- 開頭宣告「原創角色」與「不出現既有遊戲角色、Logo、UI、傷害數字」
- **每段分鏡都要重複空間關係**（左側是什麼建築、右側是什麼、遠方是什麼），
  否則模型換鏡頭就換世界
- 武器與道具寫死狀態：「全程保持展開，不可收回、不可消失、不可變形」
- 穿越動作要寫「從真正存在的空隙穿過，絕對不能穿模」
- 物理連續性約束見 video-structure.md §2，這類影片必寫
