# 提示詞框架

## §1 八欄填空表（核心）

一張圖的資訊量拆成八欄。前四欄（主體／場景／構圖／風格）決定畫面長什麼樣，
後四欄（光線／色彩／細節／比例）決定質感與用途。寫人像或情緒戲優先填色彩欄，
寫商品或場景優先填光線欄，兩欄都填也可以。

| 欄位 | 問什麼 | 可選值與寫法 |
|---|---|---|
| 1 主體 | 畫誰／畫什麼 | 越具體越好：年齡、穿搭、氣質、數量。進階寫法是同時給主體一個「正在發生的事」，讓畫面有故事而不是物件清單 |
| 2 場景 | 在哪裡 | 決定氛圍。場景越明確，畫面越有故事感 |
| 3 構圖 | 怎麼拍 | `close-up` 特寫→情緒感／`portrait` 半身→社群感／`full body` 全身→時尚感／`wide shot` 廣角→電影感／`medium shot` 中景→最穩。短影音封面常用：半身＋中景＋留白 |
| 4 風格 | 什麼調性 | `cinematic` 電影感／`luxury` 高奢／`editorial` 雜誌感／`realistic` 寫實／`anime` 動漫／`3D render` 立體渲染／`cyberpunk` 科技感。詳見 style-library.md |
| 5 光線 | 怎麼打光 | `soft light` 柔光／`rim light` 輪廓光／`neon light` 霓虹／`golden hour` 暖陽／`cinematic lighting` 電影感／`volumetric light` 體積光。**預設加 cinematic lighting** |
| 6 色彩 | 三層配色 | **核心色**＝主角身上最搶眼的顏色／**基礎色**＝場景底色／**情緒色**＝傳達情緒的小面積色（臉紅、淚光、光暈） |
| 7 細節 | 加什麼質感 | `glowing particles`／`fog`／`water drops`／`glossy texture`／`shallow depth of field`。也可按「表情／肢體／材質／場景」四類各補一句 |
| 8 比例 | 給誰看 | `1:1` IG 貼文／`4:5` IG 直式／`16:9` YouTube 與簡報／`9:16` Reels、TikTok、Shorts |

**寫作要點**：生成模型不怕寫太長，怕寫太少。描述越具體，模型越知道要什麼。

## §2 三種排版方式

同樣的內容，排版會影響模型的遵從度。依模型選：

1. **分段式**（中文常用）：用【畫面內容】【場景環境】【畫面風格】【畫質參數】【負向指令】分段。
   適合 Gemini、ChatGPT、千問這類對話式模型。
2. **一句一行**：每個指令獨立成行，不寫成段落。指令超過十條、或要求嚴格的複雜畫面時，
   遵從度通常比整段文字好。
3. **純關鍵字堆疊**：不寫句子，逗號分隔。適合 Midjourney 類模型。
   開頭留 `【主體角色】` 之類的欄位給使用者替換。

## §3 風格命名法

定位一個新風格時，用**已知風格相乘**，比形容詞堆疊精準：

> 中秋主題 × 琉璃材質 × 超萌 Q 版兔子 × 東方庭園 × 收藏級設計師玩具

三到五個乘數即可。每個乘數都要是模型認得的既有概念（IP 名、材質名、既有風格流派）。
乘數之間要能互補——一個管主題、一個管材質、一個管角色造型、一個管環境、一個管質感等級。

## §4 反推流程（從成品倒推指令）

使用者給參考圖或參考影片時走這條，五段結構：

1. **畫面分析** — 主題定位、主題一句話、要保留什麼（文字、字體、顏色、位置、排版）
2. **分鏡** — 標秒數，每段寫鏡頭運動＋角色動作＋背景變化
3. **保護清單** — 把「不准變的東西」一次列完：身份、五官、服裝、比例、道具、背景、原有文字的字型大小顏色位置排版；接著列禁止項：換臉、變形、人物消失、物件錯位、畫面閃爍、鏡頭抖動、低畫質、Logo、水印、額外字幕
4. **台詞** — 有台詞的話寫在這裡
5. **配樂建議** — 風格與音效

保護清單是這套的核心。反推時使用者最在意的通常是「別把我原本喜歡的地方改掉」——
所以先問清楚他喜歡參考成品的哪裡，把那些點全部寫進保護清單。
